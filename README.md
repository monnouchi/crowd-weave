# 雑踏突破 — 人波をぬけて、ライブへ

[ブラウザで遊ぶ](https://monnouchi.github.io/crowd-weave/)

開演前、待ち合わせた友だちとライブの最前列を目指す、一人称視点のブラウザゲームです。住宅街、駅前、カフェ、雨の会場前、ホールの全5区間を歩きます。人の向きと流れを見て、すきまが開く瞬間を選んでください。近くの人に「すみませーん」と声をかけると、応じた人が道を譲ります。

## 操作

| | スマートフォン | PC |
| --- | --- | --- |
| 左右によける | 画面下の左右ボタンを押し続ける | ← / → または A / D |
| 立ち止まって待つ | 左右を同時に押す | 左右を同時に押す、または Space |
| 声をかける | 中央の「すみませーん」を1回押す | C |
| 一時停止・再開 | 右上の一時停止ボタン | Esc。再開は Enter も可 |
| 音のオン・オフ | 右上の音ボタン | 右上の音ボタン、または M |

前へは自動で進みます。声が届くのは近くの人だけで、再使用までの時間はボタンに表示されます。人の間を無接触で抜けると短い反応があります。人に触れると少し足が止まり、到着タイムに2秒が加算されます。

駅前と会場前では信号を見て横断してください。赤信号で進むと時間が加算され、車や自転車に接触するとその区間からやり直しです。画面を離れると自動で一時停止し、時計と人の動きも止まります。各区間の結果から次へ進むか、同じ配置でその区間を再挑戦できます。最終結果からは新しい配置で最初から遊べます。

## ローカルで遊ぶ

Python 3 または Node.js があれば、このフォルダで以下のいずれかを実行し、[http://127.0.0.1:4175/](http://127.0.0.1:4175/) を開きます。

```sh
npm start
# または
python3 -m http.server 4175 --bind 127.0.0.1
```

`?seed=17` のように URL へ seed を付けると同じ人の配置で試せます。テストは `npm test`、Pages 向けの配布物は `npm run build:pages` で作成できます。

タイトルロゴはこの作品用に画像生成した `logo.png` です。人物・街並みは Canvas 2D の透視投影、音楽と効果音は Web Audio による合成です。第三者の画像・音源や実行時ライブラリは使っていません。[MIT License](LICENSE)。
