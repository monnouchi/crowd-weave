# 雑踏突破 — 人波をぬけて、ライブへ

[ブラウザで遊ぶ](https://monnouchi.github.io/crowd-weave/)

開演前、待ち合わせた友だちとライブの最前列を目指す、一人称視点のブラウザゲームです。住宅街、駅前、カフェ、雨の会場前、ホールの全5区間を歩きます。歩いてくる人の向きと流れを見て、すきまを選んでください。近くの人に「すみませーん」と声をかけると、応じた人が道を譲ります。

## 操作

| | スマートフォン | PC |
| --- | --- | --- |
| 左右によける | 画面下の左右ボタンを押し続ける | ← / → または A / D |
| 立ち止まって待つ | 左右を同時に押す | 左右を同時に押す、または Space |
| 声をかける | 中央の「すみませーん」を押す。続けて押しても可 | C。続けて押しても可 |
| 一時停止・再開 | 右上の一時停止ボタン | Esc。再開は Enter も可 |
| 音のオン・オフ | 右上の音ボタン | 右上の音ボタン、または M |

前へは自動で進みます。声が届くのは近くの人だけです。ボタンはいつでも押せ、押すたびに声と光で反応します。応じた人は空いている側を見て歩きながら道を譲り、色の違いでも分かります。人のいる区間を無接触で抜けると短い反応があり、連続して抜けると音が少し変わります。人に触れると少し足が止まり、到着タイムに2秒が加算されます。

右上の「周囲」レーダーは現在地の近くだけを上から示します。上が進行方向で、▲が自分、○が通行人、◆が動物、太線が通れない境界、縞模様の四角が車や自転車です。人や動物の薄い外周は、ぶつからず通るために必要な間隔です。道路は薄い帯で示し、通行可能な横断位置は白い目印で示します。信号の判断は進路上の信号と案内を見てください。

駅前と会場前では進路の上にある信号を見て横断してください。赤信号で進むと時間が加算され、車や自転車に接触するとその区間からやり直しです。区間の目的地に着いた時点で結果へ進みます。画面を離れると自動で一時停止し、時計と人の動きも止まります。各区間の結果から次へ進むか、同じ配置でその区間を再挑戦できます。最終結果からは最初から遊べます。通常のプレイでは新しい配置、seed 指定時は同じ配置になります。

## ローカルで遊ぶ

Python 3 があれば、このフォルダで以下のいずれかを実行し、[http://127.0.0.1:4175/](http://127.0.0.1:4175/) を開きます。`npm start` には Node.js も必要です。

```sh
npm start
# または
python3 -m http.server 4175 --bind 127.0.0.1
```

`?seed=17` のように URL へ seed を付けると同じ人の配置で試せます。結果画面から同じ配置の URL をコピーできます。同じ配置と区間の自己ベストはブラウザ内に保存され、最終結果のベストは5区間の合計です。保存できない環境でもプレイは続けられます。テストは `npm test`、Pages 向けの配布物は `npm run build:pages` で作成できます。

タイトルロゴはこの作品用に画像生成した `logo.png` です。人物・街並みは Canvas 2D の透視投影、音楽と効果音は Web Audio による合成です。第三者の画像・音源や実行時ライブラリは使っていません。[MIT License](LICENSE)。
