# ライブへ行こう！ / Crowd Weave

## 全5ステージ・斜め見下ろし立体版

[全5ステージの立体版](https://monnouchi.github.io/crowd-weave/prototype-all-3d/all-stage-3d.html?seed=17)は、現行版と入口を分けた比較用の試作です。住宅街、駅、カフェ、雨の公園と道路、ライブホールを固定視点の立体風景で歩きます。各区間の直進距離は旧版の約2倍で、人の流れが密な場所と抜ける場所を交互に進みます。人物、建物、車・自転車、信号、雨、会場の舞台と客席もオリジナルの軽量な幾何で描いています。3Dライブラリや外部画像は使わず、Canvas 2D へ投影しています。

ローカルではこのフォルダで `npm start` を実行し、`http://127.0.0.1:4175/all-stage-3d.html?seed=17` を開いてください。操作、接触・信号・車両の判定、友だちとの合流、音、各区間の結果と最終結果、やり直しは現行版と同じです。ステージ5ではホールに入るとオリジナルのロック調リズムと控えめな舞台照明に切り替わります。スマホは左右ボタン、PCは ← / → または A / D。両押しで停止し、Escape で一時停止、Enter で開始・再開できます。画面を離れたときも自動で一時停止します。

## ステージ1・斜め見下ろし3D試作（このフォルダ）

公開中の全5区間版を残した、住宅街ステージだけの試作です。[試作ページ](https://monnouchi.github.io/crowd-weave/prototype-stage1/stage1-3d.html?seed=17)は別パスで遊べます。ローカルでは `python3 -m http.server 4176 --bind 127.0.0.1` をこのフォルダで起動し、`http://127.0.0.1:4176/stage1-3d.html?seed=17` を開いてください。スマホでは左右ボタン、PCでは ← / → または A / D。両押しで停止、Escape で一時停止、Enter で開始・再開できます。人にぶつかると2秒加算。友だちに着くとタイムと接触回数が出て、同じ配置で再挑戦できます。画面を離れると自動で一時停止します。

建物と人物はオリジナルの軽量な3D幾何を固定視点で Canvas2D に投影したものです。屋根・壁・道路側の玄関・庭・道路を描き、移動、接触、ゴールは全5区間版と同じ判定を使います。外部ライブラリや素材は追加していません。

[ブラウザで遊ぶ](https://monnouchi.github.io/crowd-weave/)

人の流れをよけて友だちと合流し、ライブの最前列を目指す全5区間のゲームです。プレイ中は住宅街、駅、カフェ、雨の公園、ライブホールを真上から見ます。住宅街には散歩する人と犬、駅前とカフェには横切る人流とカフェ近くの猫、雨の会場前には信号と傘を持つ来場者と犬、ホールにはロビーの観客と最前列の人垣があります。犬猫も接触判定があり、声かけでは道をあけません。カフェには6つの横断人流と立ち話をする集まりがあります。ゴール後は客席から舞台を見上げます。青い服と「YOU」があなたで、友だちは歩いた道をついてきます。

人や信号で止まらず直進した場合の距離は、順に約14.4・14.4・18.9・27.7・22.9秒です。実際のクリア時間は、人をよける動きや信号待ち、最後の友だちの到着によって変わります。

各区間に立ち話をする2人がいて、直進すると足が止まります。左右どちらかから回り込み、人のすきまを通ってください。

## 操作とルール

- PC は ← / → または A / D、スマホは左右ボタンの長押しで移動します。左右を同時に押すとブレーキです。両方を一度離してから0.65秒以内にもう一度同時押しすると、前方の人が少し道をあけ、成功時にはYOUから波紋が広がります。約10秒の再使用待ちがあり、信号や車両には作用しません。
- 左または右を短く2回押すと、その方向へ最大36ワールド単位を素早く横移動します。入力間隔は0.34秒以内、再使用待ちは1.2秒です。人・犬猫・壁・道路の衝突判定は通常の移動と同じです。
- フィールドの左右端に当たると短い専用音が鳴ります。端へ押し続けても連打されず、離れてから再び当たると鳴ります。
- 「はじめる」を押した後、各区間の GET READY では時計と人の流れが止まり、GO! から進みます。PC は Enter でも開始・再開でき、Escape で一時停止します。
- 人への接触と赤信号での横断開始は、それぞれタイムに＋2秒。自分や友だちが車・自転車に触れると、その区間から再挑戦です。
- YOUが人に接触すると短い吹き出しで反応します。友だちが大きく遅れると「待って〜！」、赤信号で横断を始めると同行者の警告が表示されます。
- 音は開始画面やプレイ中の「音」ボタンで切り替えます。左右で歩いているときは実際の足の動きに合わせて小さな足音が鳴ります。「操作ガイド・設定」では対応スマホの傾き操作を選べます。結果画面ではタイムの確認と画像保存・共有ができます。

## ローカルで遊ぶ

Python 3 があれば `python3 -m http.server 4175 --bind 127.0.0.1` を実行し、[ローカル版](http://localhost:4175)を開きます。Node.js がある場合は `npm start` も使えます。
