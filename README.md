# ライブへ行こう！ / Crowd Weave

**[ブラウザで遊ぶ](https://monnouchi.github.io/crowd-weave/)** — インストール不要。

人の流れとすきまを読み、友だちと合流しながらライブの最前列を目指すゲームです。住宅街、駅、カフェ、雨の会場前、ライブホールの5区間を進みます。青い服・足元の光・「YOU」があなた。番号の付いた仲間は歩いた道をついてきます。

## 操作

| 操作             | PC                   | スマホ               |
| ---------------- | -------------------- | -------------------- |
| 左右によける     | ← / → または A / D   | 左右ボタンを長押し   |
| ブレーキ         | 左右を同時に押す     | 両ボタンを同時に押す |
| 開始・次へ・再開 | Enter、画面のボタン  | 画面のボタン         |
| 一時停止         | Escape、画面のボタン | 画面のボタン         |

自動で前進します。ブレーキ中も通行人は動くので、すきまを待ったり、仲間の列を整えたりできます。「操作ガイド・設定」から対応スマホの傾き操作も選べます。「正面合わせ」で基準を取り直し、専用ブレーキで停止します。許可できない端末では左右ボタンを使ってください。

## ルール

- 仲間全員が到着すると次の区間へ進めます。最後は柵の客席側の最前列へ。舞台には上がれません。
- 人への接触はタイムに＋2秒、短く足が止まります。続けて同じ人に触れても連続加算しません。
- 横断歩道は信号を見て渡りましょう。赤で渡り始めると＋2秒です。
- 一時停止や別アプリへの移動では時計も止まります。戻ったら再開ボタンを押してください。
- 完走結果に到着タイム・接触回数・信号無視回数が表示され、もう一度遊べます。

## 音と結果の共有

開始時や「音：ON/OFF」でオリジナルの音楽・効果音を切り替えられます。結果では画像保存、対応端末の標準共有、文章コピーができます。共有先は自分で選びます。

小さい画面では結果欄をスクロールできます。端末の「動きを減らす」設定に対応しています。傾き・音・共有の対応範囲はブラウザによって異なります。

## ローカルで遊ぶ・詳細

Python 3 があればリポジトリ内で `python3 -m http.server 4175 --bind 127.0.0.1` を実行し、[ローカル版](http://localhost:4175)を開きます。Node.js がある場合は `npm start` も使えます。

仕様・開発・検証の詳細は [開発資料](docs/development.md) を参照してください。
