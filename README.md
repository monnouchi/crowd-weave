# ライブへ行こう！ / Crowd Weave

[ブラウザで遊ぶ](https://monnouchi.github.io/crowd-weave/)

住宅街、駅、カフェ、雨の公園、ライブホールを真上から描いた、人の流れをよけて歩くゲームです。家の玄関から駅の改札、カフェ、会場入口まで、場所ごとの道をたどります。友だちと合流しながらライブの最前列を目指します。自宅から会場までの5区間を進みます。青い服と「YOU」があなたで、仲間は歩いた道をついてきます。

## 操作とルール

- PC は ← / → または A / D、スマホは左右ボタンの長押しで移動します。左右を同時に押すとブレーキです。
- Enter または画面のボタンで開始・再開、Escape または画面のボタンで一時停止します。
- 人への接触と赤信号での横断開始は、それぞれタイムに＋2秒。自分や仲間が車・自転車に触れると、その区間から再挑戦です。
- 「操作ガイド・設定」で音や対応スマホの傾き操作を選べます。結果画面ではタイムの確認と画像保存・共有ができます。

## ローカルで遊ぶ

Python 3 があれば `python3 -m http.server 4175 --bind 127.0.0.1` を実行し、[ローカル版](http://localhost:4175)を開きます。Node.js がある場合は `npm start` も使えます。
